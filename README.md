# ScrubLar

Локальный сервис обезличивания персональных данных в русскоязычных документах перед отправкой в LLM.

## Проблема

Сотрудники компаний копируют в ChatGPT документы с ФИО, телефонами, СНИЛС, паспортными данными. Это нарушает 152-ФЗ: трансграничная передача ПДн, штрафы до 15 млн ₽.

Инструмента, который за 2–3 минуты убрал бы ПДн из документа, у малого бизнеса нет: DLP дорого, open-source библиотеки требуют навыков программирования, Presidio плохо работает с русским (recall 0,42).

## Что делает ScrubLar

Загружаете DOCX или TXT → сервис находит ПДн (ФИО, телефон, email, СНИЛС, ИНН, паспорт) → показывает превью с подсветкой → скачиваете очищенный документ и отчёт.

Работает локально. Ничего не уходит на сторонние серверы. Маппинг «ПДн → замена» хранится только в памяти процесса.

## Статус

В разработке. MVP — к 31 октября 2026 г. Релиз v0.1.0 — к 28 ноября 2026 г.

## Установка и запуск

```bash
make install
make run
```

Откройте http://127.0.0.1:8000.

## Дисклеймер

**ScrubLar снижает риск, но не гарантирует полную защиту.** Ответственность за соблюдение 152-ФЗ остаётся на пользователе. Инструмент не заменяет DLP и не отменяет требование уведомления Роскомнадзора о трансграничной передаче.

## Стек

Python 3.13, FastAPI, python-docx, transformers, pymorphy3. Runtime-зависимости — open-source, локальный запуск, без хостинга.
