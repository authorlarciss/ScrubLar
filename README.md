# ScrubLar

Локальный сервис обезличивания персональных данных в русскоязычных документах перед отправкой в LLM.

**Версия 0.1.0.** MVP: DOCX и TXT, 6 типов ПДн (ФИО, телефон, email, СНИЛС, ИНН, паспорт), веб-интерфейс.

## Проблема

Сотрудники компаний копируют в ChatGPT документы с ФИО, телефонами, СНИЛС, паспортными данными. Это нарушает 152-ФЗ: трансграничная передача ПДн, штрафы до 15 млн ₽.

Инструмента, который за 2–3 минуты убрал бы ПДн из документа, у малого бизнеса нет: DLP дорого, open-source библиотеки требуют навыков программирования, Presidio плохо работает с русским (recall 0,42).

## Что делает ScrubLar

Загружаете DOCX или TXT → сервис находит ПДн → показывает превью с подсветкой → скачиваете очищенный документ и отчёт (JSON).

Работает локально. Ничего не уходит на сторонние серверы. Маппинг «ПДн → плейсхолдер» (`<NAME_1>`, `<PHONE_2>`) хранится только в памяти процесса.

## Установка и запуск

```bash
make install
make run
```

Откройте http://127.0.0.1:8000.

Требуется Python 3.13, [uv](https://github.com/astral-sh/uv).

## Что поддерживается

- **Форматы:** DOCX (параграфы и таблицы), TXT (UTF-8, cp1251).
- **Типы ПДн:** ФИО (полные и инициалы в формате «Фамилия И.О.»), телефон (+7/8), email, СНИЛС, ИНН (10 и 12 цифр), паспорт (XX XX NNNNNN).
- **Контрольные суммы:** СНИЛС и ИНН проверяются, all-same-digit отвергается.

## Метрики (синтетический набор, 50 документов, seed=42)

| Тип | Precision | Recall | F1 |
|---|---|---|---|
| NAME | 0.862 | 1.000 | 0.926 |
| PHONE | 1.000 | 1.000 | 1.000 |
| EMAIL | 1.000 | 1.000 | 1.000 |
| SNILS | 1.000 | 1.000 | 1.000 |
| INN | 1.000 | 1.000 | 1.000 |
| PASSPORT | 1.000 | 1.000 | 1.000 |
| **Overall** | **~0.93** | **1.000** | — |

Метрики — на синтетических документах (clean + adversarial с падежами и FP-кандидатами). Реальный benchmark на 20–30 вручную размеченных документах — v0.2.

Воспроизвести:

```bash
make evaluate ARGS="--out tmp/report.json"
```

## Известные ограничения

- **Названия компаний.** «ООО «Иванов и партнёры»» — Natasha принимает «Иванов» за ФИО. Precision NAME на синтетике 0.86 из-за этого. Контекстный слой — v0.2.
- **PDF не поддерживается.** v0.2.
- **Адреса, банковские реквизиты, ОГРН** — не покрыты. v0.2.
- **Инициалы** ловятся только в формате «Фамилия И.О.» и «Фамилия И. О.». «И.О. Фамилия» и «Фамилия И.О» (без точки) — нет.
- **Не заменяет DLP** и не отменяет уведомление Роскомнадзора о трансграничной передаче.

## Дисклеймер

**ScrubLar снижает риск, но не гарантирует полную защиту.** Ответственность за соблюдение 152-ФЗ остаётся на пользователе.

## Стек

Python 3.13, FastAPI, uvicorn, python-docx, Natasha (ONNX, 30 MB), pymorphy3. Runtime-зависимости — open-source, локальный запуск, без хостинга.

## Разработка

- `make evaluate` — отчёт по метрикам.
- `lambda/ARCHITECTURE.md` — архитектура.
- `lambda/adr/` — ADR (0007–0011, плюс унаследованные от BaseLar).
