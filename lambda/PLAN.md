# План проекта ScrubLar

## Цель

Разработать и опубликовать открытый локальный сервис ScrubLar, который обеспечивает автоматическое обнаружение и обезличивание персональных данных в русскоязычных документах перед их отправкой в сторонние LLM-сервисы.

## Задачи

1. Проанализировать требования 152-ФЗ и существующие решения (5+ по 10 критериям).
2. Реализовать ядро обезличивания: гибридный детектор (regex + NER), recall ≥ 90%, precision ≥ 85% на 50 документах, 6 типов ПДн.
3. Реализовать веб-интерфейс: DOCX/TXT, превью, скачивание + отчёт.
4. Подготовить открытый релиз с документацией и юридической справкой.
5. Провести валидацию с партнёром.

## Вехи

| 1–7 ноя | Веб-интерфейс, тестовый набор, метрики |
| 8–14 ноя | UX-тестирование, юридическая справка, **экспертиза 14 ноября** |
| 15–20 ноя | Слайды, демо, репетиция |
| 21–28 ноя | **Проект готов, защита** |

## Первый релиз

Когда MVP достигнут:

1. `omicron` → `nu`.
2. Bump версии до `0.1.0`.
3. `alpha/v0.1.0` → `beta/v0.1.0` → `gamma/v0.1.0` → `omega` + тег `v0.1.0`.
4. `omicron`, `alpha/v0.1.0`, `beta/v0.1.0`, `gamma/v0.1.0` удаляются.

## Что в MVP

- DOCX + TXT.
- 6 типов ПДн: ФИО, телефон, email, СНИЛС, ИНН, паспорт.
- Минимальный веб-интерфейс (загрузка → превью → скачивание + отчёт).
- Готовая NER-модель + постпроцессинг.
- 50 тестовых документов.
- 3–5 внешних тестировщиков.

## Что отложено (v0.2)

- PDF.
- Адреса, банковские реквизиты, ОГРН.
- Дообучение NER на своём датасете.
- 200+ документов.
- Тёмная тема, история.
