# Architecture Decision Records (ADR)

Директория содержит записи об архитектурных решениях проекта.

## Формат

Каждое решение — отдельный файл `NNNN-краткое-название.md`.

Шаблон структуры:

- **Контекст** — почему возник вопрос.
- **Решение** — что выбрано.
- **Альтернативы** — что рассматривалось и почему отклонено.
- **Последствия** — плюсы, минусы, риски.
- **Статус** — принято / устарело / заменено на ADR-NNNN.

## Правила

- Нумерация последовательная (0001, 0002, …), не переиспользуется.
- Старые ADR не редактируются. Если решение изменилось — создаётся новый ADR
  со ссылкой на предыдущий.
- Формат лёгкий: 1–2 страницы, не эссе.
